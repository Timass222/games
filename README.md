# Материалы игры о Вавилонской башне

**Для подготовки презентации заказчику:** [полный документ игры](output/vision/вавилонская_башня_финальные.html) с vision, [детальной проработкой механик](output/vision/вавилонская_башня_финальные.html#mechanics), реализованным демо и проверками GPT-агентами.

Для продолжения: [GAME_MECHANICS_PLAN.md](GAME_MECHANICS_PLAN.md) — текущий план обсуждения уровня 2 и последняя точка остановки; [GAME_VISION.md](GAME_VISION.md) — общее видение; [GAME_CONTEXT.md](GAME_CONTEXT.md) — краткий контекст. [GAME_DRAFT.md](GAME_DRAFT.md) сохраняет ранее обсуждённые подробности. Сырые расшифровки читать только выборочно.

В основном документе — 290 строк содержательного свода: актуальные договорённости, требования брифа, концепция и открытые вопросы. При восстановлении контекста читать его; полные расшифровки открывать выборочно по ссылкам. Приоритет — последние уточнения S10, затем S09. MVP: шесть команд по 3–4 человека; лидер, ресурсный человек, дипломат и помощник при четырёх участниках. Каждый проходит три формальные роли, помощником бывает максимум один сезон. Индивидуальных целей нет; критерии оценки обсуждаются, старый чек-лист не финальный. Более крупные команды отложены.

**Для команды:** [автономный HTML с vision](output/vision/концепт_док_башня.html).

**Договорённости блока 2:** [итоговый документ Word](<output/design/Вавилонская башня - договорённости блока 2.docx>) с механиками, условиями победы и рамками первого плейтеста. Внутренний документ со скрытыми условиями Ордена.

**Подготовка следующего этапа:** [пакет задач для роя агентов](SWARM_BRIEF.md) — источники, ограничения, подробные задания и порядок подготовки сюжета, карточек, экономики и проверки Sites.

**Материалы первого запуска:** [сборка «Высокая вода»](swarm_work/c1_integration/integrated.md) со ссылками на два сюжета, карточки, экономику и подготовку плейтеста. Сюжет для числового прогона и параметры выбраны предварительно.

**Проработка сайта:** [локальный цифровой прототип](site_app/README.md), [HTML-сводка правил и карточек](output/review/igra-bashnya-review.html), [расчётные варианты экономики](swarm_work/c2_balance/resource_experiments.md).

**Где остановились:** прорабатываем уровень 2, актуальные решения и вопросы — в [плане механик](GAME_MECHANICS_PLAN.md). Вариант Мелиссы — источник идей и упрощённая альтернатива. Демо — нулевой цикл и шесть основных, ориентир встречи 1 час 30 минут. Предыдущий vision и контекст могут содержать устаревшие варианты; приоритет у плана механик.

`MVP_CYCLE_DRAFT.md` — ранний подробный эскиз, оставленный для справки. Его числа, ресурсы, тайминг и полномочия не считаются автоматически принятыми.

Все восемь исходных PDF, DOCX и PPTX перенесены без изменений в [materials/originals/](materials/originals/). Полные тексты собраны отдельно в [materials/FULL_TEXTS.md](materials/FULL_TEXTS.md). Отдельные расшифровки — `materials/text/`, изображения — `materials/assets/`, реестр — `materials/manifest.json`, проверка — `materials/verification.json`.

`materials/raw/S06_failed_text_layer.md` — не использовать для чтения: сохранённый результат неудачного автоматического извлечения PDF интервью. Исправленная версия — `materials/text/S06.md`, вручную восстановленная по всем страницам.

Сборка свода из сохранённых текстов: `python materials/build_reference.py`. Первичное извлечение — `materials/extract_sources.py`, исправление табличного извлечения — `materials/repair_extraction.py`. Повторная сборка не извлекает текст заново. Ручная расшифровка интервью хранится в `materials/text/S06_visual.md`.
