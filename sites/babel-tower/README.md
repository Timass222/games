# Облачная сборка «Вавилонской башни»

Worker обслуживает существующий интерфейс и игровой движок, D1 хранит состояние и сессии. Один Site обслуживает одну текущую партию. Версия состояния проверяется при записи, чтобы одновременные ходы нескольких фракций не затирали друг друга.

Из корня общего проекта выполните `node site_app/sync-sites.mjs`, затем из этого каталога `npm ci`, `npm run build`, `npm test`. Синхронизация переносит игровой движок и четыре публичных файла. Тест использует SQLite локально и проверяет разделение ролей, изменение формата, одновременные голоса и конфликт резервов.

Sites публикует `dist/server/index.js` и применяет миграции из `drizzle/`. Для входа ведущего в настройках Sites используется секрет `GAME_HOST_EMAIL`. Нужный адрес — адрес ChatGPT-аккаунта владельца. Коды команд генерируются в базе при создании партии и читаются с панели ведущего.
